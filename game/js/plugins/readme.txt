VoiceControl.js
ADV向けボイス自動切替プラグイン
for RPGツクールMV / MZ

==================================================
概要
==================================================

文章表示中の \!（入力待ち解除）に合わせて、
ボイスを自動的に切り替えるプラグインです。

ノベルゲーム・ビジュアルアドベンチャー向けに設計されています。

==================================================
主な機能
==================================================

・VoiceStart コマンドでボイス再生開始
・\! 解除時に次のボイスへ自動切替
・前のボイスを自動停止
・OGG優先 / M4Aフォールバック
・メッセージ終了時に自動停止
・ボイス番号自動連番対応

==================================================
対応エンジン
==================================================

・RPGツクールMV
・RPGツクールMZ

==================================================
導入方法
==================================================

1. ファイル配置

js/plugins/VoiceControl.js

へ配置してください。

--------------------------------------------------

2. プラグイン有効化

RPGツクール内：

ツール
→ プラグイン管理
→ VoiceControl
→ ON

==================================================
音声ファイル配置
==================================================

保存場所：

audio/se/voice/

--------------------------------------------------

ファイル命名規則：

scene00101.ogg
scene00102.ogg
scene00103.ogg

--------------------------------------------------

規則：

[パラメータ][連番2桁].ogg

例：

scene00101.ogg
scene00102.ogg
scene00103.ogg

==================================================
使用方法
==================================================

プラグインコマンド：

VoiceStart scene001

--------------------------------------------------

文章表示例：

こんにちは。\!
今日はいい天気だね。\!
眠いな……

==================================================
動作仕様
==================================================

VoiceStart実行時：

scene00101

を再生します。

--------------------------------------------------

\!解除時：

・現在再生中ボイス停止
・次番号ボイス再生

を行います。

--------------------------------------------------

音声が既に終了していた場合：

そのまま次の音声を再生します。

--------------------------------------------------

次ファイルが存在しない場合：

何も行いません。

--------------------------------------------------

メッセージ終了時：

再生中ボイスを停止します。
